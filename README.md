# Email Recipient Selection Agent

Turn a chosen contacts list into the confirmed recipient pool for an outreach campaign. The agent pulls the list, resolves each member into a full contact record, enforces the campaign's recipient cap, and hands you a clean bundle to review and approve before drafting begins.

## Capabilities

- Resolve a chosen contacts list into the campaign's confirmed recipient pool
- Re-fetch the list from source so the recipient set never drifts from the live data
- Enforce the campaign's maximum-recipients cap before anything is saved
- Apply a recent-send cooldown filter so the same contact is not re-touched too soon
- Pause for human review and approval of the final recipient set
